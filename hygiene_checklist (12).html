This is now the checklist's real storage — every "Save" writes straight to your Google Sheet, separated automatically into one tab per month (e.g. August 2026), laid out to match this form so you can print directly from Sheets too.

One-time setup:
1. Open a blank Google Sheet → Extensions → Apps Script
2. Copy all the code from the included file google_apps_script.gs, paste it in, then Deploy → New deployment → Web app, "Who has access" = Anyone
3. Copy the deployment URL, paste it above, tap Save URL.

To make this a proper shared link (so QA or other staff can open it on their own device without you configuring anything on theirs), host this HTML file somewhere public — the easiest free option is dragging the file onto app.netlify.com/drop, which gives you a permanent URL instantly.
